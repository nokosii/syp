# 示範插畫

這六張圖片於 2026-10-02 使用 OpenAI imagegen 工具為本專案生成，作為教學主題的視覺示意。不是實地照片、受訪者肖像、歷史文件或已驗證的田野證據，人物與場景均為虛構插畫。

| 圖片 | 主題 |
| --- | --- |
| coast | 潮間帶、石滬與觀察筆記 |
| town | 街區走讀、店面與居民生活空間 |
| river | 河岸觀察與水環境學習 |
| language | 口述訪談與跨世代生活記憶 |
| farm | 作物觀察與食農教育 |
| source | 書籍、地圖與地方文獻整理 |

網站版本以 WebP 格式提供 640 與 1280 像素寬度，依畫面尺寸載入。插畫與說明不會寫入知識原文或語意索引，RAG 回答仍以原文段落為依據。未來的正式成果不會自動套用這些示範圖像。

原始生成 PNG 已保存於作者工作站的 `outputs/illustration-originals/`，不隨 GitHub 發布；公開網站使用本目錄的最佳化版本。
